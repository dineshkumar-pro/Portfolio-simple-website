# Personal Portfolio Website

This project is a simple personal portfolio website created using **HTML and basic CSS**. It is designed to showcase my profile, skills, and basic information in a clean and user-friendly layout.

## Pages

- **Home Page** – Introduces me and provides an overview of my profile.
- **contact Page** – Contains information about my skills, interests, and background.

## Technologies Used

- HTML5
- CSS3

## Features

- Simple and clean design
- Two-page portfolio website
- Easy navigation between pages
- Responsive and user-friendly layout
- Basic CSS styling

## Purpose

The main purpose of this project is to practice **HTML and CSS fundamentals** and create a simple online portfolio to showcase my profile and skills.
